# Color Blind Extension

Real-time color correction and simulation for color blindness (protanopia, deuteranopia, tritanopia, and their partial variants) to improve web navigation.

This repository includes two browser extension packages:

- `daltonismo chrome/` for Chrome / Chromium-based browsers
- `daltonismo firefox/` for Firefox

Each extension applies a matrix-based SVG filter to the active page, supports persistent saved modes, and offers a language toggle for Portuguese/English.
